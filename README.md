# 秋湖列车 · Pixel Train Wallpaper

一张会动的像素画：一台黑红相间的小蒸汽机车拉着两节红白车厢，沿着湖畔、花田、海边、小镇和河谷一直开下去，穿过隧道换景，经过车站停靠，四季、昼夜和天气都在变化。

**在线演示：<https://qaqwowqaq.github.io/pixel-train-wallpaper/>**

**整个项目只有一个 `index.html`**。不依赖任何库，没有构建步骤，也没有图片素材。画面里的每一个像素都是代码实时算出来的。声音大多用 Web Audio 现场合成，只有车轮压过钢轨接缝的"哐当"用了一小段公有领域的实录，也直接嵌在页面里（约 27 KB）。

## 运行

直接用浏览器打开 `index.html` 就能看到。

如果浏览器限制本地文件（极少数情况），可以在项目目录里起一个静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

### 当作桌面壁纸

- **macOS**：用 [Plash](https://sindresorhus.com/plash) 把这个网页设为桌面。
- **Windows**：用 [Lively Wallpaper](https://www.rocksdanister.com/lively/) 添加这个网页。

再在控制栏里打开"壁纸模式"，界面和鼠标都会藏起来，双击画面或按 <kbd>H</kbd> 可以退出。默认开启"省电"，帧率限制在 30 帧。

## 有什么

- **五种景色**：湖畔、花田、海边、小镇、河谷。列车每隔两三分钟钻进一次隧道，出来就换一种景色。
- **四季**：
  - 春天：油菜花和樱花；
  - 夏天：薰衣草和萤火虫；
  - 秋天：红叶和稻田；
  - 冬天：雪景。雪下得越久积得越厚，湖面会结冰，还有人滑冰。
- **昼夜**：黄昏、晚霞、夜晚、黎明、清晨循环；也可以选"实时"，跟随电脑的时钟和日历，月相也是真实的。
- **天气**：
  - 晴、雨（冬天变成雪）、雾、雷雨；
  - 雨停后白天可能出现彩虹；
  - 晴朗的夜里偶尔有流星。
- **蒸汽机车**：
  - 车轮和连杆跟着车速转动；
  - 烟囱冒烟，烟会拖到车厢上方，起步时烟团更大，进隧道后贴着洞顶走；
  - 夜里偶尔飘出火星，司机室亮灯，车底有炉火的光；
  - 出站时汽缸喷出白汽，鸣笛时汽笛冒白汽。
- **车站**：列车会刹车进站、开门，乘客上下车，然后鸣笛、关门开走。
- **地标车站**：湖畔的车站能看到富士山，太阳正好落在山顶后面；海边的车站能看到自由女神像；小镇的车站在巴黎铁塔下，夜里铁塔会亮灯。
- **山和天空**：
  - 远山有山脊、沟壑和雪顶，山脚融进地平线的雾气；近山上长着树林；
  - 天空是细分过的渐变，太阳周围有暖色光晕；
  - 有蓬松的积云和高空的卷云，晴朗的夜里能看到银河。
- **对向列车**：一列特快偶尔从后面的轨道呼啸而过。
- **车内视角**：坐在车厢里看窗外，有窗帘、座椅、小桌上的茶和橘子。
  - 夜里玻璃上能看到对面车厢的倒影；
  - 冬天窗边结霜，下雨时玻璃上有水珠滑落。
- **声音**：默认关闭，打开后可以听到：
  - 车轮压过钢轨接缝的"哐当"，有五种轨声可选：
    - 绿皮："哐当……哐当哐当……"；
    - 货车：老式短轨，连绵的"哐当哐当"；
    - 卧铺：隔着地板的低沉"咚咚"；
    - 轻轨：清脆的"咔嗒咔嗒"；
    - 高铁：无缝钢轨，几乎只有滚动声；
  - 过铁桥时声音更空，车内和隧道里回声更重；
  - 隧道轰鸣、雨声、雷声、海浪；
  - 蝉鸣、虫鸣；
  - 道口铃、车站开关门提示音；
  - 蒸汽汽笛：进隧道前、出站前、对向列车经过时会响，平时偶尔也会响，也可以按 <kbd>D</kbd>、点"鸣笛"按钮或直接点车头。

## 它是怎么画出来的

如果你想学习程序化像素画，下面是代码的主要思路，按在 `index.html` 里出现的顺序排列。

### 1. 低分辨率画布 + 整数倍放大

画面在一块只有约 320×180 的小画布上绘制，逐像素写进一个 `Uint32Array`（即 `ImageData` 的底层缓冲区）。然后用 CSS 的 `image-rendering: pixelated` 按整数倍放大到全屏，所以像素边缘始终是硬的。

### 2. 索引调色板

所有颜色都注册在一张调色板里（`def(name, hex, fog, em)`），场景里存的是颜色编号，而不是 RGB 值。每一帧按下面的顺序重新算一遍调色板：

1. **季节**：在春、夏、秋、冬四组颜色之间插值。冬天还会根据积雪量，在"光秃秃"和"白雪覆盖"之间过渡。
2. **时刻**：乘上当前时间的色调（`tint`）。
3. **远近雾气**：按每种颜色的 `fog` 值混入雾色，越远的东西雾越浓。
4. **自发光**：窗户、灯这类颜色（`em`）在夜里保持亮度。

所以换季节、换时间都不用重画场景，只要改调色板。

### 3. 无限滚动的视差图层

景物分成十来层，从远到近依次是云、远山、近山、树林、中景、水面、电线杆、近岸、铁轨、前景。每层有自己的视差系数 `par`，越近移动越快。

每层按 128 像素宽切成"块"（chunk）：
- 块用**固定种子**的随机数和哈希噪声生成，同一个位置无论什么时候画都一样；
- 生成结果按"块编号 + 景色类型"缓存，画面走远的块会被清掉；
- 所以画面可以无限延伸，内存却不会越吃越多。

远山和近山的明暗是这样算的：先找出山脊线上的每个山峰，每个像素归属它"最正下方"的那座山峰；在山峰右侧就是受光面，左侧是背光面（光从右边来）。再把山峰往下按角度切成很多细长的扇形，一条亮一条暗，就成了山脊和沟壑。远山最高的几座山峰带雪，雪顺着沟壑往下多延伸一段；山脚用抖动（dithering）混进地平线的颜色。近山的轮廓上加了一排高低不齐的树梢，山坡上撒了几片暗色的树林。

### 4. 景色轮换藏在隧道里

世界被切成固定长度的段落，每段开头是一条隧道。隧道完全遮住屏幕的那一瞬间才切换景色，所以看不到"接缝"。为了让连续两段景色不重复，用了一个带偏移的块状排列（`biomeOfSeg`）。

### 5. 天空

天空的四个关键色被细分成 13 级，相邻两级之间用 4×4 的 Bayer 矩阵抖动过渡，所以渐变既平滑又保留像素感。太阳附近再按距离混入太阳的颜色，太阳越低这层光晕越明显。夜里的银河是一条斜穿天空的带子，用两层噪声做出明暗不均的星云，再撒上更密的小星星。

云有三种：扁平的层云、由几个圆团叠成的积云（顶部亮、底部暗，中间抖动过渡），以及两头渐隐的细丝卷云。

### 6. 水面反射

湖面和海面的做法是：读取水线上方已经画好的像素，垂直翻转后，带一点横向波动混进水的颜色里。靠近太阳或月亮的那一列会叠加闪动的波光。

### 7. 动态元素

以下这些是每帧实时绘制的，不走缓存：
- 列车、车站和乘客；
- 蒸汽机车的车轮和连杆（按走过的距离算出转角）；
- 烟、白汽和火星（粒子在世界坐标里运动，所以会自然地落到列车后面）；
- 三个地标（富士山按角度分出雪沟，自由女神像和巴黎铁塔是手工点出来的字符画）；
- 对向列车；
- 落叶、雨雪和萤火虫；
- 闪电；
- 彩虹和流星；
- 车内视角。

车内视角的做法：把车外画面以 2 倍最近邻放大，再盖上一张预先生成的车厢遮罩（窗框、窗帘、座椅、桌子）。玻璃区域额外叠加淡青色、斜向反光、对面车厢的倒影和边缘的霜。

### 8. 声音

环境声全部由噪声缓冲区和振荡器合成：
- 雷声：长衰减的低通噪声；
- 虫鸣：一个正弦波被两个低频振荡器调制出来的；
- 雨、风、海浪、河水：不同滤波的白噪声和棕噪声。

车轮的"哐当"试过纯合成，但总是太干净，像轻轻点了一下。最后的做法是**实录样本 + 程序化节奏**：
- **样本**：从一段 CC0 的车厢内录音里自动找出每一下车轮撞击。同一个转向架的前后两根车轴先后落下，前轴是"哐"，后轴是"当"，各挑 5 下，每下截 0.24 秒，再加一段首尾无缝的滚动声循环。这些样本压成一个 22 kHz 单声道 MP3，以 base64 形式嵌在页面里。
- **节奏**：声音在"米"的尺度上计算。每节车厢有两个转向架，每个转向架有两根车轴，每根车轴压过钢轨接缝时响一次。所以节奏完全由车厢长度、钢轨长度和车速决定：钢轨长度等于车厢长度时，就是经典的"哐当……哐当哐当……"。
- **准时**：每一下都提前在音频时钟上排好，而不是等到画面那一帧才触发，所以画面降到 30 帧时节奏也不会抖。
- **不重复**：每一下从样本池里随机挑一个，音高浮动 ±5%，每个接缝的磨损程度也不同。车外听时声音从右往左扫过两节车厢。
- **厚度**：样本下面垫一层合成的低频闷响，再经过轻微的饱和和一个模拟钢铁车厢的短混响。
- **五种轨声**只是同一套样本的不同用法：换钢轨长度、车厢长度、样本音高和滤波。

汽笛是三根音管的和弦（311、370、466 Hz），每根音管都由一个三角波加上一段同频率的窄带噪声组成，噪声负责"气声"。阀门刚打开时音高偏低，然后升到正常音高；关上时音高往下掉。汽笛有自己的一路回声，在野外像山谷回响，进了隧道回声更短、更密。
